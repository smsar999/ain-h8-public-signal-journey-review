# Audit Focus — Signal Journey

The highest-priority audit question is whether the same immutable source fact remains the same fact through every boundary:

`physical generation -> source observation -> scheduled task -> durable admission -> Probability request -> model attempt/result -> episode/seal -> terminal truth -> decision/UI`

Look specifically for identity substitution, dropped durable debt, duplicate birth/terminalization, stale-result overwrite, restart resurrection and projection-before-authority.
