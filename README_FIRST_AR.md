# اقرأ هذا أولًا — مرآة مراجعة رحلة الإشارة في عين المضارب H8

هذه ليست نسخة تشغيلية من «عين المضارب»، بل **مرآة كودية عامة منقحة للمراجعة الهندسية**.

الهدف منها أن يستطيع المراجع تتبع قلب رحلة الإشارة من قراءة المصدر حتى الختم/Terminal والـUI، مع الإبقاء على منطق الـplumbing والـlifecycle الحقيقي، ومنع نشر الأجزاء الحساسة.

## ما حُذف عمدًا
- ملفات وأوزان/أشجار نموذج GANN20 الحقيقي.
- وصفة الميزات السرية ومعاملات المعايرة الفعلية للنموذج.
- الأسرار والمفاتيح وSecret Vault.
- أي Broker/Account credentials أو Connectors غير لازمة لفهم رحلة الإشارة.
- بيانات الجلسات الحية وملفات السوق التاريخية.
- مسارات جهاز المستخدم والبيانات الشخصية.

بدل نموذج GANN20 الحقيقي ستجد:

`03_signal_probability/gann20_probability_model.py`

وهو Stub عام يحافظ على حدود الواجهة التي يتعامل معها باقي النظام، لكنه **لا يستطيع إنتاج احتمال حقيقي** ولا يحتوي وصفة النموذج.

## سؤال المراجعة الأساسي
اختر `source_observation_id` واحدًا وتتبعه:

مصدر → Observation → Probability lineage → Episode → R1 → R50/R100/Terminal → Durable projection → UI.

وحاول إثبات أو نفي وجود طريق يمكن فيه أن تضيع الإشارة، تتكرر، تتأخر، ترتبط بشمعة/حلقة خاطئة، تُبعث بعد Terminal، أو تظهر في UI دون سلطة الحقيقة الدائمة.
